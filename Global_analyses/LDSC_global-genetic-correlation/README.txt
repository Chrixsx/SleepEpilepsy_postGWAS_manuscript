This section includes script to do 2 tasks:
Task 1: Run LDSC
Task 2: Create correlation plot (Figure 2) for publication

Task 1 includes 3 steps:
  Step 1: generate munge file from orginal GWAS summary statistics.
  Step 2: Estimate SNP-based heritability of each trait.
  Step 3: Calculate pair-wise genetic correlation between each sleep-epilepsy trait pair.
